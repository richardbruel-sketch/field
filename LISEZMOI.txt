FIELD (bêta, version sans serveur)
Aucun Node.js requis : ce sont des fichiers statiques, l'écoute radio part directement de l'appareil de chaque utilisateur.
Mettre en ligne (gratuit, en https) : glisser-déposer le dossier sur Netlify Drop, ou GitHub Pages, ou Cloudflare Pages. Le lien obtenu s'ouvre sur tous les appareils.
Installer : navigateur > "Ajouter à l'écran d'accueil".
Matchs : modifier matchs.json (debut en ISO avec fuseau, source : radio / free / abroad / none). Radio : 0 RMC, 1 franceinfo, 2 Europe 1, 3 à 6 ici.
Avis des amis : renseigner l'e-mail dans const CONTACT au début du script de index.html.
Animations 2D : football, voile, golf, tennis, Formule 1 (scenes.js), pour l instant avec des données simulées, signalées dans l appli.
Classements : vue Classement (football et rugby) via ESPN, adresse standings (non officielle).
Pro D2 : pas de calendrier automatique (absente d ESPN) ; ajouter les matchs dans matchs.json, voir exemple-pro-d2.json. Favoris et mode clair : boutons dans l appli.
Rugby : calendrier ESPN (Top 14, Champions Cup, Six Nations, Coupe du monde, tests), diffusions dans diffusions.json (à vérifier).
Circuits F1 : convertisseur-circuits.html transforme un tracé GeoJSON ou GPX en circuits.json.
Compétitions internationales : Ligue des nations, amicaux, Coupe du monde, Euro (liste CP dans index.html). Diffusion gratuite TF1 notée seulement pour les matchs de la France en Ligue des nations (à vérifier).
Calendrier football : lu chaque jour via ESPN (source non officielle, à remplacer par un fournisseur sous licence avant toute vente) ; diffusions : diffusions.json. Option ?demo dans l adresse pour voir les animations des autres sports.
Flux de données : voir FORMAT_FLUX.md ; pour tester, renommer matchs-test.json en matchs.json.
Limite : une radio qui ne propose qu'un flux http ne peut pas être lue depuis une page https ; l'appli affiche alors un lien vers le site de la radio.
